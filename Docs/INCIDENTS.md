# 再発防止記録

## 2026-09-03 毎日用事前確認の初回テスト探索に失敗

- 原因: 新しいPowerShellラッパーがPythonテストファイルを絶対パスで渡した一方、同じフォルダーの`daily_diary.py`をPythonの探索先へ入れていなかった。
- 影響: 隔離テストの読込み前に停止した。外部通信、資格情報読取り、DB書込み、投稿は0件。
- 対応: テストフォルダーへ一時的に作業位置を移し、`finally`で必ず元へ戻してからテストを実行するよう修正した。
- 再確認: 2026-09-04 12:00相当で同じ日次事前確認を再実行し、23件の計画検査、当日`ready`判定、外部実行無効、クライアント隔離5試験の合格を確認した。
- 次回: 別フォルダーから呼ぶ運用スクリプトは、対象モジュールの探索位置と終了後の復帰を最初の隔離試験に含める。

## 2026-09-03 Render公開先が94.1秒後も起動待ち

- 原因: 公開先はRenderの起動中画面を返し続けた。Render公式上、無料Webサービスは15分間受信がないと休止し、復帰に約1分かかるが、今回の94.1秒はその目安を超えた。サービス内部や実際のプランは未確認のため、休止だけが原因とは断定しない。
- 影響: 共通基準の操作可能20秒以内を満たさず、9月3日分の外部投稿と本番確認を安全停止した。
- 対応: 自動投稿クライアントを単発90秒要求から、30秒単位・最大180秒でCSRF付き画面を待つ再試行へ変更した。明示フラグがない登録・投稿は資格情報を読まずドライランで止める。
- 再確認: 外部通信なしの5試験で、起動待ち、接続失敗、上限停止、登録・投稿の安全既定が合格した。実サービスの起動時間は未改善。
- 次回: 外部投稿前に公開ログイン画面が操作可能か確認し、20秒超過時は投稿を強行せず、サービス状態・費用・代替運用を人が判断する。

## 2026-09-03 英語製品名のアポストロフィで名称試験が1件不一致

- 原因: 英語名のASCIIアポストロフィが安全なHTMLエスケープで`&#39;`へ変換され、文字列一致試験が表示意図と実装表現の差を検出した。
- 影響: 名称変更後の初回`verify`が31件中1件失敗した。外部通信、本番DB、ローカルH2、利用者データには触れていない。
- 対応: 表示名を`Takaki Okuyama’s Gratitude Diary`のタイポグラフィックアポストロフィへ日英資源、テンプレート、テストで統一した。HTMLエスケープ自体は弱めていない。
- 再確認: Maven単一ワーカーで31件成功、失敗0、エラー0、スキップ0。JAR生成と日英実画面を再確認した。
- 次回: 公開名称の句読点も翻訳資源の正本へ含め、テンプレート値と安全なレンダリング結果を一緒に検査する。

## 2026-09-03 PowerShell表示で日本語ログが文字化け

- 原因: Maven／Javaの出力文字コードと、呼出し元PowerShellの表示文字コードが一致しなかった。
- 影響: コンソール上の日本語ログだけが読みにくくなった。テスト入力、ソース、JAR、DBには変更なし。
- 対応: 合否はSurefireの構造化結果と終了コードで確認し、日本語ログ表示だけから製品不具合を判定しない。
- 再確認: Java 21.0.12、Maven単一ワーカーで31件成功、失敗0、エラー0、スキップ0、JAR生成成功。
- 次回: 人が読むログを保存する場合だけ、実行前にUTF-8入出力を明示する。秘密値や日記本文は保存しない。

## 既知の隔離環境差

- 原因: 隔離実行ユーザーでは、別ユーザーが所有するMavenキャッシュにアクセスできない場合がある。
- 影響: 製品コードではなく依存キャッシュの権限差により、検証開始前に停止する。
- 対応: 実際の作業ユーザーが所有する既存キャッシュを使用し、アクセス権を広げない。必要な場合はプロジェクト専用キャッシュを用意する。
- 再確認: 通常Windows環境では`mvnw.cmd -T 1 verify`が成功した。
