# プライバシー公開前チェック

## 結論

プライバシー画面と日英表示は実装済みです。問い合わせ先は、公開済みGitHubプロフィールを指す「仮問い合わせ窓口」で補いました。非公開フォームではないこと、秘密情報・個人情報を送らないことを日英で明示しています。ただし、次の運用情報が未確定のため、現時点の変更を本番へ公開しません。

1. 利用者が非公開で連絡できる正式な問い合わせ先
2. RenderとNeonの実際の保存地域・利用プラン
3. 削除依頼、バックアップ、アクセスログの具体的な保存期間と対応担当

既定値は`https://github.com/OkuyamaTakaki`です。正式窓口が決まったら、個人のメールアドレスをソースへ固定せず、Renderの環境変数 `APP_PRIVACY_CONTACT_URL` に `https://` または `mailto:` で始まる連絡先を設定します。不正な形式の場合、画面は公開前の警告を表示し、リンクを生成しません。

## 公開前の確認手順

1. 上記3項目を運営者が決め、正式窓口へ切り替える場合は`APP_PRIVACY_CONTACT_URL`をRenderへ設定する。
2. `src/main/resources/messages.properties` と `messages_en.properties` の説明を実際の運用へ合わせる。
3. `./mvnw clean verify` を実行し、`/privacy` が認証前に日本語・英語で開くことを確認する。
4. ログイン、登録、日記画面のフッターからプライバシー画面へ移動できることを確認する。
5. 本番HTTPSでCookie属性、問い合わせリンク、RenderとNeonの最新規約を確認する。

## 保守時に更新する条件

保存項目、外部事業者、Cookie、解析、広告、問い合わせ先、保存期間、削除方法のいずれかを変更したときは、実装と同時に日英両方のプライバシー文面を更新します。秘密情報や利用者の日記内容をGitHub Issueへ投稿しません。
